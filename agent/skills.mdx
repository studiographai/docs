title: "Skills"

---

A skill is a saved set of instructions for the agent — a repeatable task or a house style. "How we write case studies", "our weekly report format", "the checklist for onboarding a new client". The agent loads a skill when it's relevant, or when you ask for it.

A skill is an entry, so it lives in a folder, and the folder decides who can use it. A skill in your private folder is yours alone; a skill in a shared folder works for everyone who can see that folder.

## Creating a skill

Create one from the **New** menu: choose **More types…**, then **Skill**. A skill has three parts:

- **Name** — what you'll call it.
- **Description** — one line saying when the skill applies. This matters most: the agent reads skill descriptions to decide which one to use, so describe the situation ("Use when writing a client case study"), not just the topic.
- **The body** — plain instructions: the task, the steps, the tone, whatever the agent should follow. No special format is required.

For example, a "Weekly report" skill might describe which folders to pull updates from, the section order, and how long each section should be.

<Tip>
Just finished walking the agent through something you'll want again? Ask it to write the skill for you: "save what we just did as a skill". It turns the steps you worked out together into a skill entry, asks which folder to keep it in, and you can edit it afterward like any other entry.
</Tip>

## Using a skill

You don't have to do anything special. When a request matches a skill — "write up the Meridian project as a case study" — the agent loads the matching skill and follows it.

To choose a skill yourself, start your message with **/** and pick one from the list, or name it: "use the weekly report skill".

## Skills that come with Studiograph

The agent also has built-in skills for Studiograph's own work — building artifacts, working with datasets, laying out paged documents, and writing new skills. On Studiograph Cloud, the **Getting Started** folder adds house-style skills for presentations, publications, diagrams, infographics, landing pages, and social media, plus skills for working with data and applying your brand. Edit them to match how your team works.
