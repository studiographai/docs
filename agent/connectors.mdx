---
title: "Connectors"
description: "Let the agent work with your other tools — project trackers, docs, code, email, and more."
---

Connectors give the agent access to the tools your team already uses — Linear, Notion, Asana, GitHub, Superhuman, and more. Once connected, you can ask things like "create a Linear issue for this bug" or "find the Notion page about our pricing", and the agent does it in that tool.

Connectors live in the **Studio**: open the account menu (your avatar in the top-right corner), choose **Studio**, then **Connectors**. No connectors are set up out of the box. A workspace Owner adds each one once, then each person connects their own account.

## Adding a connector (Owners)

<Steps>
<Step title="Open Studio → Connectors">
Only workspace Owners can add connectors.
</Step>
<Step title="Add the tool">
Open **Add from catalog** to pick from supported tools, grouped by category. Click **Connect** on a tool that signs in through the browser — this adds it to the workspace and starts your own sign-in in one step. Tools that use an API key show **Add** instead.

For a tool that isn't in the catalog, choose **Add External Connector** and paste its server address. Any MCP-compatible server works.
</Step>
</Steps>

## Connecting your account

Each person connects on their own, from the same **Connectors** page:

- Click **Connect** next to the tool and sign in with your account in the browser.
- If the tool has a shared connection (marked **Shared**), you'll see **Connect as me** instead — use it to sign in with your own account rather than the shared one.

Once you're connected, the tool shows **Connected (OAuth)**, and the agent acts as you in that tool — it sees what you can see there, and anything it creates is created by you. A tool connected with an API key shows **Connected (API key)**; with that kind of connection, everyone shares one identity in the tool.

<Info>
Your connection is yours. Signing in gives the agent access on your behalf only — it doesn't change what anyone else can do in that tool.
</Info>

## Disconnecting

To disconnect, click the **Connected (OAuth)** badge. This revokes the agent's access to that tool for your account; you can reconnect later.

If a connection stops working, the tool shows **Reconnect** — click it to sign in again — or **Not accepted** if the tool refused the sign-in. Both states also offer **Disconnect**.

Owners can remove a connector from the whole workspace with **Remove connector**, in the connector's **Danger zone**.
