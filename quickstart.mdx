## Install the CLI

```bash
npm install -g studiograph
```

Requires Node.js 20+ and Git. macOS (Apple Silicon), Linux (x64/arm64), and Windows (x64/arm64) are supported. Intel Macs are not — a LanceDB dependency lacks a prebuilt binary.

## Create a workspace

```bash
studiograph init "My Studio"
cd my-studio
```

`init` creates an empty workspace with a `.studiograph/` config directory. Pass `--demo` to scaffold the `meridian-rebrand` example project for exploring features. Pass `--github --github-org my-org` to provision GitHub repos at the same time.

## Start the server

```bash
studiograph serve
```

The server runs on port 8000 by default. The first time you open `http://localhost:8000` in a browser, the **Setup** page asks you to create the first owner account.

## Add team members

From the CLI:

```bash
studiograph user add alice@example.com --name "Alice Chen" --role member
```

Or from **Settings → Manage Team** in the web UI. New users land on the login page; once signed in, they see their auto-provisioned **My Entries** folder.

## Capture your first entries

The fastest way to populate the graph is the agent. Click the chat panel toggle, then ask:

- "Set up my workspace" — kicks off the owner interview that scaffolds organization, projects, clients, and processes.
- "Add a meeting note about the kickoff today with Jane and Bob"
- "Create a project called Website Redesign"

You can also use the homepage capture box (paste text, drop files, paste a URL) or type entries directly via the **+** button in the sidebar.

## Connect AI tools (optional)

Studiograph exposes an MCP server so Claude Code, Claude Desktop, Cursor, and other MCP clients can read and write your graph.

1. Open **Settings → Connectors → Studiograph MCP**
2. Click **Mint token** — copy the `sg_…` token (shown once)
3. Paste the JSON snippet into your MCP client's config

See [MCP integration](/cli/mcp) for details.
