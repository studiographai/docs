## What is Studiograph?

Studiograph turns your team's scattered information into a connected knowledge graph and gives AI agents direct access to it. Every person, project, meeting, decision, and deliverable becomes a structured entity that links to everything related, stored as Markdown with YAML frontmatter and tracked in Git.

The result: AI work that reflects your real team context, not generic output.

## How it fits together

- **Workspaces** are root directories containing config and folders. Each workspace runs a single multi-user server.
- **Folders** are Git repos within a workspace — one per project, function, or shared resource.
- **Entities** are typed Markdown files with YAML frontmatter, connected via wikilinks.
- **The agent** reads, writes, and traverses the graph through built-in tools and skills, and can call out to external services via MCP connectors.
- **MCP** exposes the same graph to Claude Code, Claude Desktop, Cursor, and any other MCP client through Streamable HTTP or stdio.
