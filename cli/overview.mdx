## Overview

The `studiograph` CLI is the primary interface for managing your knowledge graph. It covers workspace setup, daily workflow, data sync, server operations, and integrations.

The CLI uses **folder** as the user-facing term for a Git repo within a workspace. Older docs and APIs may still call these "repos."

## Command groups

### Getting started

| Command | Description |
|---|---|
| `init <team-name> [dir]` | Create a new workspace (`--demo` for example data, `--github` to push to GitHub) |
| `join <server-url> [dir]` | Join a workspace hosted on a Studiograph server |
| `clone <server-url> [dir]` | Clone a workspace with full admin setup |

### Daily workflow

| Command | Description |
|---|---|
| `start` | Launch the agent chat interface |
| `pull` | Pull latest changes across folders (add `--remote <url>` for config sync) |
| `push [folder]` | Push local commits (add `--remote <url> --data` for full sync) |
| `commit` | Git commit entity changes across all folders |

### Workspace management

| Command | Description |
|---|---|
| `about` | Display or edit workspace identity (`ABOUT.md`) |
| `folder add/list/rename/remove` | Manage folders |
| `index` | Build search index (FTS + optional semantic) |
| `lint` | Check entity completeness against schemas |
| `orphans` | Find entities with zero inbound references |
| `config` | Manage user configuration (`~/.studiograph/user.json`) |
| `sync <folder>` | Pull new entities from configured sources |

### Server and deployment

| Command | Description |
|---|---|
| `serve` | Start the HTTP server (Graph API, chat, webhooks, collab) |
| `user add/list/remove` | Manage user accounts |
| `deploy railway` | Guided Railway deployment |
| `redeploy [project]` | Trigger a redeploy with a fresh build |

### Integrations

| Command | Description |
|---|---|
| `mcp [workspace]` | Start the stdio MCP server for local AI tools |
| `connector add/list/remove` | Manage external MCP connectors |
| `r2 setup/upload/sync` | Manage Cloudflare R2 asset storage |

### Maintenance

| Command | Description |
|---|---|
| `reset` | Reset workspace data (keeps configuration) |
| `clear` | Clear agent sessions, memory, or both |
| `update` | Check for and install updates |

See [Commands](/cli/commands) for full options on each command.
