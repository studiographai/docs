## Requirements

- **Node.js 20+**
- **Git**
- An API key from a supported LLM provider (Anthropic, OpenAI, Google, xAI, Groq, or OpenRouter)
- Supported platforms: macOS (Apple Silicon), Linux (x64/arm64), Windows (x64/arm64)

<Note>
Intel Macs are not supported. The LanceDB dependency that powers search lacks a prebuilt binary for `darwin-x64`.
</Note>

## Install via npm

```bash
npm install -g studiograph
```

The package ships both the CLI (`studiograph`) and the bundled web UI used by `studiograph serve`.

## Verify installation

```bash
studiograph --version
```

## Update

```bash
npm update -g studiograph
```

Or use the built-in updater, which checks the npm registry and self-installs:

```bash
studiograph update          # check
studiograph update --force  # install latest
```

## Install pre-release builds

`@next` is the dev channel — published from feature branches:

```bash
npm install -g studiograph@next
```

`@latest` (the default) is production.

## Configure an LLM provider

Once installed, set your provider and key. The first run of `studiograph start` or `studiograph serve` also prompts for these interactively.

```bash
studiograph config set model_provider anthropic
studiograph config set api_key sk-ant-...
```

Optional: enable hybrid semantic search with a Voyage AI key.

```bash
studiograph config set voyage_api_key pa-...
studiograph index
```
